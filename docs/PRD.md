# wifi-buddy（Wi-Fi 小管家）产品与功能设计文档

> **版本**：V1.0（桌面跨平台版规划）  
> **目标平台**：macOS（Apple Silicon / Intel） & Windows（Win 10 / Win 11）  
> **代码仓库**：`https://github.com/tieke1121/wifi-buddy`

---

## 1. 产品目标与定位

### 1.1 一句话定位
面向普通非技术用户（“小白”）的**跨平台桌面 Wi-Fi 小管家**，把晦涩的局域网扫描、网络排障和路由器管理翻译成大白话和一键操作。

### 1.2 核心解决的三大痛点
1. **不知道谁在连我的网**：路由器后台晦涩难懂，只看到一堆 IP 和 MAC 地址，不知道有没有被蹭网。
2. **找不到/不会改 Wi-Fi 密码**：亲友来了想连网记不住密码；怀疑被蹭网想改密码，却找不到路由器入口或怕改断网。
3. **分不清为什么网慢**：卡顿时只会拔电源重启，不知道到底是“房间信号太差”、“有人占满网速”还是“宽带运营商断了”。

### 1.3 产品设计原则
- **默认零术语**：主界面不直接暴露 IP、MAC、TTL、DNS、子网掩码等专业名词，默认展示“设备图标 + 人话名称 + 品牌 + 状态红绿灯”，技术细节折叠进“展开详情”。
- **通用底座开箱即用**：**核心 80% 功能不挑路由器品牌、不需要路由器密码**，下载安装即可运行。
- **路由器控制渐进增强**：软件自动识别用户家里的路由器品牌——已适配的型号提供一键改密/踢人；未适配或运营商锁定的光猫，优雅降级为“一键打开后台 + 图文引导”。
- **隐私本地优先**：设备备注、扫描记录、路由器凭据全部保存在用户本地（SQLite + 系统钥匙串/凭据管理器），绝不上传云端。

### 1.4 非目标（明确边界）
- 不承诺通过破解或越权方式绕过路由器管理员认证。
- 不承诺通吃市面上所有冷门品牌或被运营商锁死权限的光猫改密接口。
- 不做抓包嗅探、端口渗透等专业网管/安全审计功能。

## 2. 跨平台桌面端技术选型（macOS + Windows）

### 2.1 推荐架构：**Tauri 2.0 + React/Tailwind + Rust（本地网络引擎）**

| 层级 | 选型方案 | 选型理由 |
| :--- | :--- | :--- |
| **桌面容器与托盘** | **Tauri 2.0** | 同时打包 macOS `.dmg/.app` 与 Windows `.msi/.exe`；安装包体积轻量（约 10MB 级），原生支持系统菜单栏/托盘常驻与桌面通知。 |
| **前端界面** | **React + TypeScript + Tailwind CSS** | 与交互原型视觉风格一致，响应式卡片布局，开发迭代快。 |
| **本地网络与系统引擎** | **Rust 核心库（可选辅助系统命令）** | 无外部运行时依赖（用户电脑无需安装 Python/Node）；高性能并发扫描局域网并直接调用双端系统 API。 |
| **本地数据存储** | **SQLite（设备库/历史记录）+ 系统钥匙串** | 设备备注与上下线记录存 SQLite；路由器管理员密码存 macOS Keychain / Windows Credential Manager。 |

### 2.2 macOS vs Windows 系统差异适配矩阵

| 能力项 | macOS 实现方式 | Windows 实现方式 | 注意事项 |
| :--- | :--- | :--- | :--- |
| **获取当前 Wi-Fi 名称/信号** | CoreWLAN（需定位权限）或 `ipconfig` / `system_profiler` | Win32 `Wlanapi`（`WlanQueryInterface`）或 `netsh wlan show interfaces` | macOS 获取真实 SSID 需申请定位权限，未授权时可优雅提示授权 |
| **读取本机已连 Wi-Fi 密码** | `security find-generic-password` 读取系统钥匙串（触发一次系统密码授权） | `netsh wlan show profile name="<SSID>" key=clear` | **免登路由器**即可生成亲友扫码连网二维码 |
| **子网扫描与 ARP 表** | 并发 ICMP/TCP 探测 + 读取 `arp -na` | 并发 `SendARP`（Win32 IP Helper API）或 ICMP + 读取 `arp -a` | Windows 上 `SendARP` 比纯 Ping 更稳定，不易受设备防火墙禁 Ping 影响 |
| **mDNS / SSDP 设备识别** | 内置 mDNS + SSDP UDP 多播发现 | 内置 mDNS + SSDP UDP 多播发现 | 跨平台统一 Rust 实现，识别电视、音箱、Mac、Android 名称 |
| **托盘常驻与开机自启** | 顶部菜单栏图标（Popover 摘要卡片） | 右下角系统托盘图标（Popup 摘要卡片） | Tauri `tray-icon` + `autostart` 插件统一封装 |

## 3. 功能模块详细设计

### 模块 1：设备雷达与防蹭网（通用核心，免路由器密码）

#### 1.1 多源局域网发现
1. **全网段探测**：自动识别当前活跃 Wi-Fi 网卡与子网（如 `192.168.5.0/24`），并发探测在线主机，结合 ARP 表捕获“禁 Ping 但在线”的设备。
2. **名称与型号提取**：
   - **mDNS/Bonjour**：获取如 `wannadeMacBook-Pro.local`、`Android-9.local` 等名称。
   - **SSDP/UPnP**：主动发现智能电视、投影仪、路由器、音响、打印机的友好设备名与型号。
   - **NetBIOS（Windows 生态辅助）**：补充识别局域网内的 Windows PC 主机名。
3. **离线 OUI 厂商与类型推断**：
   - 内置精简 IEEE OUI 厂商数据库（覆盖主流手机、电脑、路由器、家电厂商）。
   - **随机 MAC 自动识别**：检测 MAC 地址首字节本地管理位（Local Administered Bit），对现代手机/笔记本的隐私随机 MAC 标注为“手机/电脑（已开启随机 MAC）”，消除用户疑惑。

#### 1.2 熟人库与新设备警报
- **一键备注与分类**：用户可将设备命名为“我的电脑”、“客厅电视”、“妈妈的手机”，并归类为“我的设备 / 家人朋友 / 家居办公”。
- **新设备标黄预警**：对比本地 SQLite 历史设备库，发现未曾见过的 MAC 或主机名时，顶部高亮显示“⚠️ 发现 N 台陌生新设备”，支持系统桌面弹窗通知。
- **使用人数参考估算**：基于“个人移动终端数量”与“固定/IoT 设备数量”分层展示，避免把智能插座也算成人头。

---

### 模块 2：Wi-Fi 密码查看与扫码分享（通用核心 + 路由器联动）

1. **当前 Wi-Fi 密码一键查看（免路由器）**
   - 直接从本机系统安全存储读取当前所连 Wi-Fi 的密码（默认星号遮罩，点击“显示”或身份校验后可见）。
2. **亲友扫码直连卡片**
   - 生成标准 Wi-Fi 二维码（格式：`WIFI:T:WPA;S:<SSID>;P:<密码>;;`），支持手机系统相机直接识别连接。
   - 一键复制“Wi-Fi 名称 + 密码”文本卡片发微信。
3. **修改 Wi-Fi 名称与密码（联动模块 4）**
   - 提供实时密码强度条（弱/一般/强）和“生成好记强密码”按钮（如 `Sunny@3829` 单词+数字组合）。
   - 提交前明确告知：“修改后家里所有设备需要用新密码重新连一次”。

---

### 模块 3：一键网络体检（通用核心，免路由器密码）

将排错拆解为三步，最终只给**红绿灯结论 + 下一步行动建议**：

| 检测阶段 | 检测指标 | 异常时给小白的人话结论与建议 |
| :--- | :--- | :--- |
| **1. 本机 ↔ 路由器** | Wi-Fi 信号强度（RSSI）、网关延迟、抖动与丢包率 | **“宽带没坏，是这里 Wi-Fi 信号太弱”** → 建议靠近路由器、切换 2.4G/5G 或增加子路由。 |
| **2. 路由器 ↔ 外网** | 多节点公共 DNS 解析耗时、HTTPS 连通性 | **“家里 Wi-Fi 是好的，但宽带断了/卡了”** → 建议重启光猫/路由器，检查光猫是否亮红灯，或联系运营商报修。 |
| **3. 带宽与负载（可选）** | 轻量下载/上传测速 | 翻译为场景能力：*“当前约 180 Mbps，看 4K 视频、开视频会议非常流畅”*。 |

---

### 模块 4：路由器指纹识别与控制适配器（插件化设计）

解决“不知道普通用户家里什么路由器”的核心机制：

#### 4.1 自动指纹识别
连上网络后自动探测默认网关（如 `192.168.5.1`）：
1. 查询网关 MAC 地址所属厂商（如中兴、TP-Link、小米、华为、华硕）。
2. 请求网关首页提取页面标题、跳转域名（如 `zte.home`、`miwifi.com`、`tplogin.cn`）或特征接口。
3. 自动匹配最合适的控制策略，**不需要小白自己选品牌型号**。

#### 4.2 统一适配器接口与降级策略
定义标准化 `RouterAdapter` 接口（内部包含：`check_support`、`login`、`list_wifi_clients`、`update_wifi_config`、`block_mac`、`set_guest_wifi`、`reboot`）：
- **路径 A：已适配型号**（优先实现：中兴 `zte.home` 常见系列、OpenWrt、小米/TP-Link 常见家用型号）
  - 首次弹窗验证路由器管理员密码后，解锁：纯无线设备列表（2.4G/5G）、一键改密、踢出拉黑、访客 Wi-Fi、一键重启。
- **路径 B：未适配型号 / 运营商锁定光猫（降级助手）**
  - 不报技术错误，转为展示**“路由器快捷助手”**：
    1. 一键在默认浏览器打开路由器后台地址（`http://192.168.x.1`）。
    2. 展示该品牌常见的初始密码查看提示（“翻看路由器背面贴纸”）和 3 步改密图解。

---

### 模块 5：桌面常驻与新手引导

1. **首次启动 30 秒向导**：
   - 自动完成第一次局域网扫描 → 高亮本机 → 引导用户随手给 1~2 台常用手机起名 → 进入主面板。
2. **菜单栏 / 托盘快速面板**：
   - 状态图标旁可显示极简状态（如 `58 台在线` 或正常绿点）。
   - 点击托盘弹出迷你卡片：快速查看新设备提醒、一键复制 Wi-Fi 密码/二维码、一键体检。

## 6. 关键技术风险与应对

1. **macOS 定位权限与本地网络权限**：macOS 14/15 起，获取真实 Wi-Fi SSID 需要定位权限，扫描局域网需要“本地网络”权限。应对：在首次启动向导里用大白话解释授权原因，未授权时提供“手动输入 Wi-Fi 名”兜底，不卡死主流程。
2. **手机随机 MAC 导致重复“新设备”提醒**：iOS/Android 开启私有地址后，切换或重置网络可能换 MAC。应对：在提醒文案中温和提示“如果是家人手机请点击合并或改备注”，同时提供“静默模式 / 仅在打开软件时提醒”选项。
3. **路由器固件碎片化**：通过“网关指纹识别 + 适配器注册表 + 浏览器降级向导”确保任何用户装上都能正常使用核心功能。
