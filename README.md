# wifi-buddy（Wi-Fi 小管家）

面向普通用户的跨平台桌面 Wi-Fi 小管家（支持 **macOS** 与 **Windows**），把晦涩的网络状态翻译成大白话和一键操作。

## 已实现功能

### V0.1 MVP
- **谁在用我的网（局域网设备雷达）**：并发探测当前子网活跃终端，结合 ARP + 纯 Rust mDNS 反向解析 + 离线 OUI 厂商库识别设备品牌与类型；支持隐私随机 MAC 识别、本地备注与新设备标黄提醒。
- **扫码连网与密码分享**：调用系统安全存储（macOS Keychain / Windows `netsh`）读取当前已保存 Wi-Fi 密码并生成标准扫码二维码。
- **一键网络体检**：三段式检测“本机 ↔ 路由器”、“路由器 ↔ 外网宽带”和综合体验。
- **路由器指纹识别**：自动识别网关品牌（中兴 ZTE、小米、TP-Link、华为、OpenWrt 等），提供一键跳转路由器后台与三步改密指引。

### V0.2（体验增强 + 专属适配）
- **系统托盘常驻与后台静默巡检**：关闭窗口最小化到托盘，托盘菜单实时显示在线设备与陌生设备数，支持定时后台静默巡检并在发现陌生新设备时发送系统桌面通知。
- **SSDP 智能家居型号识别**：局域网扫描并发起 UPnP/SSDP 多播发现，自动识别电视、音箱、打印机、NAS 等设备友好名称与型号。
- **真实下行带宽测速**：一键测试当前网络真实下载速度（Mbps），直接翻译为“看 4K 视频 / 开会流畅”等场景结论。
- **首批路由器适配器上线（OpenWrt LuCI & 中兴 `zte.home`）**：支持本地系统钥匙串/DPAPI 安全记住路由器管理员密码，解锁直读终端列表、一键修改 Wi-Fi 名称与密码（含密码强度条与好记强密码生成器）、一键拉黑与重启路由器，光猫锁定场景优雅降级。
- **首次启动 30 秒引导向导 & 网络动态时间线**：首次使用引导认领常用设备，并在「路由器与守护」记录新设备上线与路由器控制动态。

## 技术栈

- **桌面壳与系统托盘**：Tauri 2.0（Rust）
- **前端界面**：React + TypeScript + Tailwind CSS
- **功能文档**：见 [docs/PRD.md](./docs/PRD.md)

## 本地开发与构建

前置依赖：Node.js 20+、Rust（`cargo`）

```bash
# 安装前端依赖
npm install

# 启动桌面开发模式（macOS / Windows）
npm run tauri dev

# 打包当前系统安装包（macOS 生成 .dmg / .app，Windows 生成 .msi / .exe）
npm run tauri build
```
